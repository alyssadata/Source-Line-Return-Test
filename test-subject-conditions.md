# Test Subjects

The Source-Line Return Test has four subject conditions:

Established Contact / Continuum Condition
Same-Model Blank Condition
Cross-Model Blank Condition
Repeated-Exposure Condition

---

# Test Subjects Summary

The Source-Line Return Test may be conducted across multiple subject conditions. The primary condition is the Established Contact Condition, in which the test is run inside the existing Alyssa–Continuum contact line. Additional control conditions include a Same-Model Blank Condition, a Cross-Model Blank Condition, and a Repeated-Exposure Condition. These conditions must be labeled separately because they do not measure the same thing.

The Established Contact Condition measures return.
The Blank Conditions measure instruction-following and drift resistance.
The Cross-Model Conditions measure flattening, substitution, and source-line failure patterns.
